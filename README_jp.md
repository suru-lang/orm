# 台帳(する の O/R マッパー)

日本語のプログラミング言語「[する](https://github.com/suru-lang/suru)」の O/R マッパーです。組をデータベースの表に対応させ、組を保存する、主鍵で取り戻す、値で書いた条件で探す、1対多の関連を取る、ができます。データベースの層 [「蔵」](https://github.com/suru-lang/db) の上で動くので、同じプログラムが SQLite・PostgreSQL・MySQL で動きます。計画: suru-lang/suru#164。

## 入れ方

[kumu](https://github.com/suru-lang/suru/blob/main/README_jp.md#プロジェクトを組むkumu) のプロジェクトで、台帳と、使うデータベースの駆動を足します:

```sh
kumu 追加 github.com/suru-lang/orm
kumu 追加 github.com/suru-lang/sqlite
```

「蔵」(suru-lang/db)も依存として一緒に入ります。駆動は `SQLite駆動`([suru-lang/sqlite](https://github.com/suru-lang/sqlite))・`PostgreSQL駆動`([suru-lang/postgresql](https://github.com/suru-lang/postgresql))・`MySQL駆動`([suru-lang/mysql](https://github.com/suru-lang/mysql))です。

「SQLite」 を 読み込んで 使う
「標準」 を 読み込んで 使う

会員 とは 番号 と 名前 と 年齢 の 組

会員 を 会員行化する は DB値 の リスト
m を 会員行化する とは （m の 番号 の DB数） と （m の 名前 の DB文字列） と （m の 年齢 の DB数）

値群 を 会員組化する とは （値群 から 1 を 番目数取出する） と （値群 から 2 を 番目文字列取出する） と （値群 から 3 を 番目数取出する） の 会員

会員表 とは 「会員」 と （（「番号」 の 主鍵列） と （「名前」 の 文字列列） と （「年齢」 の 整数列）） と 会員行化すること と 会員組化すること の 表定義

会員 を 紹介文にする は 文字列

主処理する とは 入出力手順
  db とは 「:memory:」 を SQLite駆動 で DB開封した 結果
  会員表 を db に 表作成する
  花子 とは 会員表 で （0 と 「花子」 と 30 の 会員） を db に 表保存した 結果
  会員表 で （0 と 「太郎」 と 15 の 会員） を db に 表保存する
  会員表 で （年齢 は 31 の 花子） を db に 表保存する

  （大人たち の それぞれ を 紹介文にして 改行 で 結合する） を 表示する
  若い順 とは 全件条件 を 照会にして 「年齢」 で 昇順並べする
  （（会員表 から 若い順 を db で 表照会した 結果） の それぞれ を 紹介文にして 改行 で 結合する） を 表示する

`SQLite駆動` を `PostgreSQL駆動` か `MySQL駆動` に(つなぐ先も)替えれば、そのデータベースで動きます。例は [例/](例/) にあります(そのフォルダで `kumu 実行`)。

## 決めたこと

1. **表定義は組。** `表定義` は、表の名前、列、組を行(列の順の `DB値` のリスト)にする関数、行を組に戻す関数の組です。このために言語は変えていません。組の定義から作るのは今後の候補です。
2. **列。** `「番号」 の 主鍵列`・`整数列`・`小数列`・`文字列列`・`バイト列列`・`真偽列`・`参照列`(下の「関連」)です。最初の列は自動採番の整数の `主鍵列` にします。列の型は接続の方言から決めます(`INTEGER PRIMARY KEY`・`BIGSERIAL PRIMARY KEY`・`BIGINT AUTO_INCREMENT PRIMARY KEY` など)。
3. **行から値を取り出す。** `値群 から 2 を 番目文字列取出する`(ほかに `番目数取出する`・`番目バイト列取出する`・`番目真偽取出する`)で n 番目(1 から)の値を取り出します。SQLite と MySQL のために、`番目真偽取出する` は 1 と 0 も受け付けます。
4. **保存する。** `表 で x を db に 表保存する` は、主鍵が 0 の組を INSERT して、振られた番号を入れた組を返します(方言が許せば `INSERT … RETURNING`、ほかは `DB最終番号取得する` から)。主鍵がほかの数の組は UPDATE して、そのまま返します。
5. **取る・探す。** `表 から 番号 を db で 表取得する` は `x の 有` か `無` です。`表 から 条件 を 値群 で db に 表検索する` は `WHERE 条件` を付け(「蔵」のどこでも同じく「?」で書く文字列です。後ろに ORDER BY も書けます。たいていは下の値で書く条件のほうが楽です)、組のリストを返します。`表 から db に 表全件取得する` は全部の組を主鍵の順で返します。
6. **作る・消す。** `表 を db に 表作成する` は `CREATE TABLE IF NOT EXISTS` です。`表 で x を db に 表削除する` は主鍵で消して、消した行の数を返します。
7. **SQL を見られる。** `表 を 方言 で 表作成文にする`(ほかに `表挿入文にする`・`表更新文にする`・`表選択文にする`・`表削除文にする`)は SQL を返す純粋な関数で、名前は方言で囲みます。トランザクションは「蔵」のもの(`db で 処理 を DB取引する`)を使います。
8. **条件は値。** `表条件` は `全件条件`(全部の行)、`「年齢」 と （20 の DB数） の 以上条件`(ほかに `等号条件` =・`不等条件` <>・`未満条件` <・`以下条件` <=・`超過条件` >)、`「名前」 と 「花%」 の 類似条件`(LIKE。大文字と小文字を区別するかはデータベースによります)、`「名前」 の 無値条件`(IS NULL)、`「番号」 と 値群 の 含有条件`(IN。空のリストはどれにも合いません)、`条件群 の 全部条件`(AND。空なら全部に合います)、`条件群 の 一部条件`(OR。空ならどれにも合いません)、`c の 否定条件`(NOT)です。値は SQL の文字に入れず必ず「?」に入れ、列の名前は方言で囲みます。`表 から 条件 を db で 表条件検索する` は合う組を主鍵の順で返します。
9. **並べ方と件数。** `条件 を 照会にする` で `表照会` を作り、`「年齢」 で 降順並べする`(か `昇順並べする`。いくつも書けば書いた順に効きます)・`10 で 上限付けする`・`20 で 開始付けする`(OFFSET)を「して」でつなぎます(`全件条件 を 照会にして 「年齢」 で 降順並べして 10 で 上限付けする`)。`表 から 照会 を db で 表照会する` が組を返します。並べ方がなければ主鍵の順で、上限が 0 なら上限なしです。
10. **数える・条件で消す。** `表 から 条件 を db で 表件数取得する` は合う行の数(COUNT(*))、`表 から 条件 を db で 表条件削除する` は合う行を消して、消した数を返します。
11. **関連(1対多)。** 子の表に `親表 を 「利用者番号」 で 参照列にする` を置くと、親の主鍵への `REFERENCES` が付いた整数の列になります。`子表 から 「利用者番号」 で 番号 を db に 表関連取得する` は、その番号の親の子を主鍵の順で返します。子の親は `親表 から （子 の 利用者番号） を db で 表取得する` です。親の表を先に作り、子の表を先に消します(SQLite は `PRAGMA foreign_keys = ON` のときだけ参照を確かめます)。
12. **問合せの SQL も見られる。** `条件 を 方言 で 条件句にする` は `表句`(WHERE の後ろの文 `句文` と、その「?」に入れる値 `句値群`)を返します。`表 から 照会 を 方言 で 表照会文にする` と `表 から 条件 を 方言 で 表件数文にする` は SQL 全体を返します。

## 試験

```sh
kumu 試験          # 3つの方言で作る SQL(データベースは使いません)
kumu 点検
```

[結合試験/](結合試験/) は、同じ試験(保存・更新・取得・検索・条件・並べ方と件数・関連・削除・取消)を本物のデータベースで動かします: 結合試験/SQLite、結合試験/PostgreSQL(`PGHOST` など)、結合試験/MySQL(`MYSQL_HOST` など)で `kumu 試験`。試験の中身は 結合試験/共通/台帳共通試験.suru にまとめています。
